# Разбор записи экрана

Конвейер проверен на четырёх роликах. Исходник во всех случаях 1920×1080, 60 fps.

---

## 0. Что сказать игроку до съёмки

Выдавать этот блок **до** того, как он начнёт записывать, а не после неудачного
разбора.

1. Записать экран через штатную запись macOS, затем **перетащить готовый файл
   на рабочий стол**. Файл, перетащенный прямо из уведомления, лежит во временной
   папке системы, и оттуда его не прочитать.
2. Вести курсор **медленно, задерживаясь на каждой иконке 1,5 секунды**.
   Меньше секунды не годится, см. раздел «Сколько держать курсор» ниже.
3. Открыть вкладку класса в листе персонажа и пройти по **всем** кругам
   заклинаний, включая верхний ряд фокусов. Верхний ряд забывают чаще всего.
4. Навести курсор отдельно на СЛ спасброска заклинаний и на бонус атаки
   заклинанием. С иконок они не читаются.
5. Открыть вкладку «Общие»: заклинания от расы и предметов, действия класса,
   включаемые пассивные.
6. Открыть панель ответных действий и показать режим каждой строки, «авто»
   или «спрашивать».
7. Продиктовать голосом или написать текстом раскладку ячеек по кругам. С экрана
   она не считается, а угадывание уже один раз дало ошибку.

После последнего шага прислать файл и написать «готово».

---

## 1. Найти файл

Имя файла содержит кириллицу в форме NFD. **Прямой путь не работает**, ffprobe
и ffmpeg отвечают `No such file or directory`, хотя файл на месте. Единственный
рабочий обход это `cd` в каталог и glob.

```bash
cd /Users/a.stepanenkov/Desktop && f=$(ls -t *.mov | head -1) && echo "$f"
```

Когда роликов несколько, работает частичный glob по времени в имени:

```bash
cd /Users/a.stepanenkov/Desktop && f=$(ls *11.20.10*.mov) && echo "$f"
```

Bash-шелл сбрасывает cwd между вызовами, поэтому `cd` повторять в каждой команде.

## 2. Метаданные

```bash
cd /Users/a.stepanenkov/Desktop && f=$(ls -t *.mov | head -1) && ffprobe -v error \
  -show_entries format=duration \
  -show_entries stream=width,height,r_frame_rate,codec_name \
  -of default=noprint_wrappers=1 "$f"
```

## 3. Подобрать кроп пробным кадром

Дешёвый шаг, который экономит целый прогон. Снять один кадр, обрезать его,
прочитать, и только потом гнать всё видео.

```bash
cd /Users/a.stepanenkov/Desktop && f=$(ls -t *.mov | head -1) && ffmpeg -v error \
  -ss 20 -i "$f" -frames:v 1 -q:v 2 "$S/probe_raw.jpg"

ffmpeg -v error -i "$S/probe_raw.jpg" -vf "crop=1500:900:0:120" -q:v 2 "$S/probe1.jpg"
```

`$S` это каталог скретчпада сессии. Кадры складывать туда, **не в репозиторий**.

Два кропа, оба проверенно читаемые: `1500:900:0:120` и `1500:820:0:195`.
Выбирать по фактическому положению панели тултипа на пробном кадре.

## 4. Нарезать кадры с дедупликацией

```bash
cd /Users/a.stepanenkov/Desktop && f=$(ls -t *.mov | head -1) && ffmpeg -v error -i "$f" \
  -vf "fps=4,crop=1500:900:0:120,mpdecimate=hi=64*200:lo=64*60:frac=0.06,setpts=N/FRAME_RATE/TB" \
  -vsync vfr -q:v 2 "$S/t_%03d.jpg"
```

**`fps=4`, а не 2.** Дедупликация всё равно выбрасывает одинаковые кадры, так
что на выходе прибавляется немного, а запас по выдержке курсора удваивается.
Таблица ниже снята на `fps=2`, при `fps=4` кадров выйдет примерно в полтора
раза больше.

Что получалось на практике:

| Длительность ролика | Настройки | Кадров |
|---|---|---|
| 88 с | без кропа, `hi=64*40:lo=64*10:frac=0.15` | 170, почти все дубли |
| 88 с | `crop=1080:920:440:140`, `frac=0.02` | 174, дедуп слишком слабый |
| 88 с | `crop=1500:820:0:195`, `frac=0.06` | 71, дальше 36 пар |
| 50 с | `crop=1500:900:0:120`, `frac=0.06` | 44, дальше 22 пары |
| 69 с | то же | 33, дальше 17 пар |
| 13 с | то же | 14, дальше 7 пар |

Ориентир: примерно один кадр на секунду ролика. Если вышло вдвое больше, дедуп
слабый, поднять `frac`.

## 5. Склеить попарно и читать

Два кадра за один вызов Read, это вдвое дешевле.

```bash
ffmpeg -v error -i "$S/t_001.jpg" -i "$S/t_002.jpg" -filter_complex vstack \
  -q:v 2 "$S/pair/p_01.jpg"
```

Циклом по всем кадрам:

```bash
mkdir -p "$S/pair"
n=0
set -- "$S"/t_*.jpg
while [ "$#" -gt 0 ]
do
  n=$((n+1))
  out=$(printf "%s/pair/p_%02d.jpg" "$S" "$n")
  if [ "$#" -ge 2 ]
  then
    ffmpeg -v error -i "$1" -i "$2" -filter_complex vstack -q:v 2 "$out"
    shift 2
  else
    cp "$1" "$out"
    shift
  fi
done
```

Цикл проверен запуском на семи кадрах: три пары плюс нечётный хвост копией,
ни один кадр не потерян. Вариант с `awk` по номеру строки не использовать, он
пропускает кадры и склеивает не тех соседей.

Текст тултипов при таком кропе читается уверенно.

## Сколько держать курсор

Арифметика, а не ощущение.

| Нарезка | Кадр раз в | Выдержка 0,5 с | Выдержка 1 с | Выдержка 1,5 с |
|---|---|---|---|---|
| `fps=2` | 0,5 с | 1 кадр | 2 кадра | 3 кадра |
| `fps=4` | 0,25 с | 2 кадра | 4 кадра | 6 кадров |

Одного кадра мало: попап проявляется с анимацией, и единственный пойманный кадр
часто застаёт текст полупрозрачным, а сам попап смещённым за курсором. Нужно
минимум **два чистых кадра** на предмет.

**Что говорить игроку: держать 1,5 секунды.** Это три кадра даже на `fps=2` и
шесть на `fps=4`, то есть запас есть при любой нарезке. Полсекунды не годится
ни при какой.

## Ловушки

**Файл из `/var/folders/.../TemporaryItems/NSIRD_screencaptureui_*/`.**
macOS отдаёт `Operation not permitted`, и `dangerouslyDisableSandbox: true`
не помогает. Именно там лежит запись, которую игрок перетаскивает прямо из
уведомления. Правильный ответ сразу, без попыток обойти:
«Перетащи ролик на рабочий стол и пришли ещё раз.»

**ImageMagick не установлен.** `magick`, `montage`, `convert` все три отвечают
`not found`. Вся склейка делается фильтрами ffmpeg.

**Контактные листы `scale=480:270,tile=5x4` это тупик.** Девять листов по 20
кадров были построены и просмотрены, для тултипов бесполезны: на 480×270 текст
не читается. Не строить их даже как опцию.

**Иконки хотбара около 28 пикселей не читаются в принципе.** Видны цвета и
примерные формы. Угадывать нельзя. Лечится только наведённым тултипом.

## Как формулировать просьбу переснять

Не «пришли ещё видео», а точный список того, чего не хватает, с указанием, где
это лежит в интерфейсе, и с оценкой, что от этого зависит. Образец формулировки:

> Не хватает трёх вещей. Верхний ряд фокусов на вкладке класса, три метамагии,
> и режим «авто или спрашивать» на панели ответных действий. От первого зависит
> выбор амулета, от второго вывод про респек. Сними эти три экрана, курсор веди
> медленно.

Если чего-то нет и после пересъёмки, поле остаётся в разделе «не распознано»
спеки с явной пометкой, а рекомендации, которые от него зависят, помечаются
условными или снимаются.
