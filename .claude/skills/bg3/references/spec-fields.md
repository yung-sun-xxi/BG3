# Чек-лист полей спеки

Двадцать шесть позиций. Каждая появилась из конкретной дырки в разборе. Пометки
показывают, чем обошёлся пропуск, чтобы не спорить, надо ли поле.

Файл спеки называется `<имя>-spec.md`, латиницей. Структура: таблицы по блокам,
в конце обязательный раздел «Не распознано».

---

## Базовое

| Поле | Заметка |
|---|---|
| 1. Класс, подкласс, уровень | |

| 3. ОЗ, КЗ, инициатива, скорость, ночное зрение | |
| 4. Бонус мастерства | нужен для формулы СЛ |
| 5. Характеристики и бонусы спасбросков | |
| 6. Навыки с владением | |

## Поля, которые не снялись с первого раза

| Поле | Чем обошёлся пропуск |
|---|---|
| 7. **Панель заклинаний целиком, вкладка класса** | первое видео было только инвентарём. Ни одного фокуса, ни одного известного заклинания. Три рекомендации висели условными |
| 8. **Фокусы, верхний ряд** | не сняли даже со второго видео. От них зависел выбор амулета, и оказалось, что подходящих фокусов у персонажа нет |
| 9. **Названия и описания с наведённого тултипа** | иконки около 28 пикселей не читаются, угадывать нельзя. Текст тултипа сохранять дословно: это официальная локализация и высший авторитет по названию и эффекту |
| 10. **СЛ спасброска заклинаний и бонус атаки заклинанием** | появились только со второго видео. Поле зависимое: бонус атаки менялся с +7 на +8 при смене предметов, значит фиксировать вместе с составом снаряжения |
| 11. **Раскладка ячеек по кругам** | с экрана не считается, игрок диктует голосом. Предположение «4/3/3/2» оказалось неверным |

## Поля, которых не было в структуре и которые добавляли задним числом

| Поле | Чем обошёлся пропуск |
|---|---|
| 12. **Ответные действия с режимом «авто» или «спрашивать»** | самая ценная находка всего разбора. Одна реакция стояла на «авто» и глушила фит. Без колонки режима это не видно |
| 13. **Владения оружием и бронёй, отдельной строкой** | без строки «короткие луки: нет» не объяснить надпись «Нет умения» на надетом луке и то, что лук носится ради пассивок |
| 14. **Метамагия: какие именно три** | без этого поля не видно, что нет ключевых метамагий, а это главный аргумент за респек |
| 15. **Черты, и отдельно признак «брал ли повышение характеристик»** | нужно для арифметики пойнт-бая |
| 16. **Потрачены ли перманентные усилители характеристик** | Волосы карги, Зеркало утраты. Метод: снять расовый бонус, сложить стоимость по таблице пойнт-бая, сравнить с 27. Сошлось ровно 27 значит ничего не потрачено |
| 17. **Разделение «заклинания класса» и «заклинания от расы и предметов»** | отдельная вкладка «Общие» в игре. Без разделения заклинание волшебника с тултипа амулета было записано как доступное чародею |
| 18. **Заклинания подкласса, не занимающие слот известных** | пять заклинаний с 6 уровня пересчитали весь бюджет: слотов больше, чем игрок думал |
| 19. **Устойчивости сводным списком** | собираются из расы, подкласса и трёх предметов, на одном экране их нет. Понадобились, чтобы показать конфликт с осью билда |
| 20. **Настройки игры** | кармические кубики включены по умолчанию и бьют ровно по механике билда. Раздел появился только на третий день |
| 21. **Сложность прохождения** | не была установлена ни разу, все расчёты по боссам шли с оговоркой «Тактик или Сбалансированный» |
| 22. **Установленные моды** | мод «Correct Counterspell Ability Score» меняет механику Контрзаклинания. Поля не было |
| 23. **Что потеряно безвозвратно** | предметы с убитых торговцев и погибших NPC. Без раздела рекомендации указывали на недостижимые вещи |
| 24. **Как игрок реально играет** | самый крупный пробел. Файл описывал один режим, играл игрок совсем другим. Ревью по файлу советовало не тому билду |

## Три вопроса, которыми заканчивается scan

Задавать всегда, ответ идёт в спеку отдельным разделом. Считать до ответов нельзя.

1. Какие заклинания ты реально кастуешь каждый бой?
2. Что ни разу не пригодилось?
3. Чем вообще ни разу не пользовался?

Мёртвый слот виден отсюда, а не из теории.

## Раздел «Не распознано»

Обязателен в каждой спеке. По строке на поле, с указанием, что переснять и что
от этого поля зависит. Рекомендация, опирающаяся на нераспознанное поле, либо
помечается условной, либо не выдаётся.
