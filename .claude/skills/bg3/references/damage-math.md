# Расчёт урона

Главный файл скилла. Всё, что тут написано, восстановлено из чисел трёх сессий и
проверено обратным счётом до десятой доли.

---

## 0. Два правила, которые нарушать нельзя

**Правило 1. Над каждой таблицей урона подписан режим расчёта.**

Одной строкой, прямо над таблицей, до первой цифры. Ровно один из двух:

```
Режим A (точный). Цель: <имя>. СЛ спасброска <N>. Спасбросок цели <характеристика> <+K>.
p_провал = (N − 1 − K) / 20 = <проценты>.
```
```
Режим B (допущение). Цель неизвестна, p_провал = 50%. Множитель ожидания 0,75
для заклинаний с половиной урона на успешном спасброске.
```
```
Режим C (сырой урон). Множитель спасброска НЕ применён. Числа сравнимы только
между собой внутри этой таблицы и ни с какой таблицей режима A или B.
```

Режим C нужен, когда сравниваются заклинания по одной и той же цели: спасбросок
у них общий и сокращается. Ставить его подписью явно, а не оговоркой под
таблицей. Именно смешение C и B дало в архиве несравнимые 56 и 54.

Без подписи таблица недействительна. В архиве прошлых сессий рядом лежат 54
(с множителем спасброска) и 56 (без него) по одному и тому же билду, и они
несравнимы. Числа из таблиц с разными режимами между собой не сравнивать никогда.

**Правило 2. В каждой строке таблицы урона есть колонка «Стоит».**

Значения: `действие + ячейка N круга`, `действие`, `бонусное действие`,
`реакция + ячейка`, `реакция`, `бесплатно`. Итог всегда приводится к **одному
действию**. Классификация в разделе 7.

**Следствие обоих правил: число без показанной арифметики не называется вообще.**
Либо строка вида `8d6 = 28, ×2 промокший = 56, ×0,75 = 42`, либо молчание.
Числа вида «300-450 урона за бой» и «~200 за три хода» в архиве есть, арифметики
под ними нет, повторять их нельзя.

## 1. Формула ожидаемого урона

```
D_base   = средний урон кубиков
           Nd4 → N×2,5   Nd6 → N×3,5   Nd8 → N×4,5   Nd10 → N×5,5   Nd12 → N×6,5
D_full   = D_base × множитель типа урона + плоские надбавки
E_цель   = p_провал × D_full  +  (1 − p_провал) × D_full/2
E_итог   = E_цель × количество целей
```

Второе слагаемое существует только у заклинаний с пометкой «on save: half damage».
У бинарных заклинаний (Паралич, Пурга, любой контроль) оно равно нулю:
`E_цель = p_провал × D_full`.

Для заклинаний с броском атаки формула другая:
```
E_цель = p_попадания × D_full
```
Криты не учитываются нигде. Разброс не считается, кубик берётся средним.

## 2. Откуда берётся p_провал

**Режим A, точный, когда статблок цели известен.**
```
p_провал = (СЛ − 1 − бонус спасброска цели) / 20
```
Проверки на реальных числах:
- СЛ 14, цель с МДР +5: (14−1−5)/20 = 40%
- СЛ 14, цель с ЛОВ +2: (14−1−2)/20 = 55%
- СЛ 15, цель с +5: (15−1−5)/20 = 45%
- Обратный счёт: чтобы p_провал упал до 5%, у цели должен быть бонус около +12

**Режим B, допущение, когда цель не названа.**
```
p_провал = 0,5
E = 0,5 × D_full + 0,5 × D_full/2 = 0,75 × D_full
```
Множитель **0,75** и есть весь режим B для половинящихся заклинаний. Для бинарных
в режиме B множитель 0,5.

Проверки множителя 0,75:
- Конус холода по мокрой цели: 8d8 = 36, ×2 = 72, ×0,75 = **54**
- Смертельное облако, один тик: 5d8 = 22,5, ×0,75 = **16,9**
- Вызов молний по мокрой цели: 3d10 = 16,5, ×2 = 33, ×0,75 = **24,7**
- Лишняя ячейка 4 круга на Удар молнии: 9d6 = 31,5, ×2 = 63, ×0,75 = **47**

## 3. СЛ спасброска и бонус атаки

```
СЛ = 8 + бонус мастерства + модификатор заклинательной характеристики + надбавки предметов
```
Пример: 8 + 3 (мастерство на 8 уровне) + 3 (ХАР 17) = 14.

Надбавки к СЛ с разных предметов **складываются**, это не выбор одного из них.

```
бонус атаки заклинанием = бонус мастерства + модификатор характеристики + надбавки предметов
p_попадания = (21 − (КЗ цели − бонус атаки)) / 20
```
Проверка: атака +8 против КЗ 15 требует 7 и выше, это 14 исходов из 20 = **70%**.

**Правило, которое надо повторять игроку:** либо кубик кидаешь ты и попадаешь
(бонус атаки), либо кубик кидает враг и уворачивается (СЛ). Одно из двух, никогда
оба. Исключение единственное: Магический снаряд, у него ни того, ни другого.

Объяснение СЛ, которое зашло игроку, именно в таком порядке: «СЛ это число,
которое враг должен выбить, чтобы увернуться» → «выпало 13, плюс 2 = 15, 15 больше
14, значит увернулся» → формула → «не путать с бонусом атаки».

## 4. Множители типа урона и порядок их применения

```
D_full = D_base
         × 2    если уязвимость
         × 0,5  если устойчивость
         × 0    если иммунитет
         − плоский вычет цели, ОДИН РАЗ НА КАЖДЫЙ ЭКЗЕМПЛЯР УРОНА
```

Уязвимость и устойчивость **гасят друг друга до ×1**. Иммунитет не пробивается
ничем, даже уязвимостью.

Три следствия:

1. **Смешанный урон удваивается по частям.** У Ледяной бури удваивается только
   холодная половина (4d6), дробящая (2d8) нет.
2. **Плоские вычеты убивают многоснарядные заклинания.** Вычет −2 снимает по 2
   с каждого из трёх дротиков Магического снаряда, то есть −6.
3. **Промокший снимает устойчивость.** Мокрый враг с устойчивостью к холоду
   получает обычный урон вместо половины.

**Промокший (Wet)**: уязвимость к молнии и холоду (×2), устойчивость к огню,
иммунитет к горению. Цель, уже имевшая устойчивость к молнии или холоду, эту
устойчивость теряет, но уязвимости не получает. Промокание снимает невидимость.

Оговорка, которую надо озвучивать честно: порядок применения при **успешном**
спасброске против уязвимости на вики прямо не написан. Вывод из двух множителей
такой: половина от удвоенного равна полному обычному урону. Это аргумент
«ты не можешь проиграть этот размен», но это вывод, а не цитата.

## 5. Помеха и преимущество на спасбросок

```
p_провал_с_помехой = 1 − (1 − p_провал)²
```
Проверки:
- 40% → 1 − 0,6² = **64%**
- 55% → 1 − 0,45² = **79,75%**
- 45% → 1 − 0,55² = **69,75%**
- 5% → 1 − 0,95² = **9,75%**

Правило распределения помехи: у половинящихся заклинаний помеха даёт примерно
+12-15% урона, у бинарных все +25 пунктов вероятности. Значит помеха и метамагия
Усиленное тратятся на **бинарные** заклинания (Паралич, Пурга), а не на урон.

Оговорка: Усиленное даёт помеху только на **первый** спасбросок. На повторные
спасброски (Паралич повторяется в конце каждого хода цели) оно не действует.

## 6. Надбавки от предметов

Все три вида, встреченные в сессиях, считались как **плоская добавка к D_base
до применения множителей**.

- **Надбавка к фокусам** (вида «+ модификатор ХАР к урону стихийного фокуса»)
  пересчитывается в **урон за бой**, а не за каст. Фокус кастуется 2-3 раза за
  бой, значит +3 за каст это +6-9 за бой. Это и убило рекомендацию по такому
  амулету: +6-9 против +47 у амулета, дающего лишнюю ячейку 4 круга.
- **Надбавка к типу урона** (вида «+бонус мастерства урона молнией ко всем
  молниевым заклинаниям») прибавляется один раз к D_base.
- **Заряды молнии**: +1 к атаке и +1 урона за заряд, при 5 зарядах они тратятся
  на следующем уроне и добавляют 1d8. Отсюда приём: Магический снаряд это
  зарядник, три дротика по 2 заряда дают 6 зарядов за один каст 1 круга.
- **Реакции на урон типа X** (вида «4 урона всем врагам в 6 м») это не надбавка,
  а **отдельный экземпляр урона**. Считать строкой, а не множителем. Проверять
  список заклинаний, по которым такая пассивка срабатывает: он бывает
  фиксированным, а не «любой урон нужного типа».

**Предмет сравнивается с предметом через урон за бой, а не через описание
эффекта.** Если данных на число нет, рекомендация не выдаётся, а формулируется
как вопрос.

## 7. Что тратит действие

| Стоимость | Что туда попадает |
|---|---|
| Действие + ячейка | обычный урон-каст, первый каст облака или поверхности |
| Действие, ячейки нет | повтор и рекаст-перемещение уже стоящего заклинания, фокусы, заклинания с предметов раз за отдых |
| Бонусное действие | Туманный шаг, движение от пассивки подкласса, любое заклинание под Ускоренным (3 очка чародейства) |
| Реакция + ячейка | Щит (ячейка 1 круга на каждое срабатывание) |
| Реакция, бесплатно | Боевой заклинатель, расовые реакции раз за отдых |
| Бесплатно совсем | авто-реакции, не тратящие реакцию раунда, тик поверхности или облака |

**«Бесплатно» почти всегда значит «не тратит ячейку», а действие тратит.**
Эта подмена один раз перевернула весь вывод: повтор заклинания давал 33 за
действие против 56 у каста из ячейки 3 круга, но был записан как бесплатный.

**Ускоренное заклинание это не +X% урона, это второе действие.** Оценивать
соответственно.

**Баф на следующий удар считается двухходовкой против двухходовки**, а не
эффектом против нуля. Шаблон в расчёте 3 ниже.

## 8. AoE и тики

Урон по нескольким целям считается **линейным умножением**: одна цель 54, три
цели 162. Никаких поправок на перекрытие области, на разные спасброски целей и
на то, что часть целей умрёт раньше. Дружественный огонь в число не входит и
называется отдельной строкой.

Тик поверхности или облака считается **за ход**, число ходов задаётся сценарием
и подписывается: «идеальный случай, три хода» и «один тик, враг ушёл» это два
разных числа, и оба надо показать.

## 9. Допущения по умолчанию

- `p_провал = 50%`, когда цель не названа (режим B)
- Сложность **Тактик**, если игрок не сказал иное. При расчёте по боссу
  оговаривать: Тактик и Сбалансированный отличаются по КЗ, ОЗ и наличию
  Легендарного сопротивления
- Кубик = среднее, разброс не считается
- Криты не учитываются
- Фокус кастуется 2-3 раза за бой
- Бой = 3 хода
- Расходники в расчёт не входят никогда
- Кармические кубики у игрока по умолчанию включены и сдвигают распределение
  к среднему. Это отдельный разговор, а не поправка в формуле

## 10. Три эталонных расчёта

Самопроверка формулы. Если новый расчёт этим трём не соответствует, ошибка
в новом расчёте.

### Расчёт 1. AoE-урон против облака, режим B

```
Режим B. p_провал = 50%. Цель мокрая. СЛ 15.

Конус холода         8d8 = 36 холодом
                     мокрый, уязвимость ×2 → 72
                     E = 0,5×72 + 0,5×36 = 54          Стоит: действие + ячейка 5
                     по трём целям = 54 × 3 = 162

Смертельное облако   5d8 = 22,5 ядом
                     мокрый на яд не влияет → 22,5
                     E за тик = 0,5×22,5 + 0,5×11,25 = 16,875
                     три хода = 50,6                    Стоит: действие + ячейка 5
                     один тик (враг ушёл) = 16,9
                     по нежити и конструктам = 0 (иммунитет к яду)
```
Вывод: сравнивать надо 54 за одно действие против 16,9 за то же действие в
реалистичном случае, а не против идеальных 50,6.

### Расчёт 2. Босс с устойчивостью и плоским вычетом, режим C

```
Режим C, сырой урон, множитель спасброска не применён.
Цель: Apostle of Myrkul. КЗ 20, ОЗ 390 (Тактик), нежить.
Устойчивость к некротическому и холоду, иммунитет к яду.
Спасброски ЛОВ +2 / ВЫН +6 / МДР +7 / ХАР +11. Все входящие удары −2.
СЛ игрока 14 → p_провал по ЛОВ = (14−1−2)/20 = 55%.
Цель промокшая.

Удар молнии, ячейка IV   9d6 = 31,5 → ×2 мокрый = 63 → −2 = 61
Вызов молний             3d10 = 16,5 → ×2 = 33 → −2 = 31
Ледяная буря             2d8 = 9 дробящее (не удваивается)
                       + 4d6 = 14 холод, ×2 мокрый ×0,5 устойчивость = 14
                         = 23 → −2 = 21
Конус холода             8d8 = 36, ×2 ×0,5 = 36 → −2 = 34
Магический снаряд        3d4+3 = 10,5, −2 на каждый из трёх дротиков = 4,5
```
Это режим C. Числа сравнимы между собой, потому что цель и спасбросок у них
общие. Рядом с числами расчёта 1 их ставить нельзя: сначала домножить на
p_провал по формуле раздела 1 и переподписать таблицу режимом A.

Вывод по этим числам: бить молнией по ЛОВ, холодом не бить (устойчивость гасит
удвоение), бросками атаки не бить (КЗ 20 против +8 это 45%), контроль не тратить.

### Расчёт 3. Баф на следующий удар, шаблон

```
Режим A. Цель КЗ 15, бонус атаки заклинанием +8 → p_попадания = 70%.

С бафом «следующий бросок атаки не промахнётся»:
   ход 1 = 0 урона (каст стоит действия и концентрации)
   ход 2 = фокус 2d10 = 11, попадание почти гарантировано
   за два хода = 11

Без бафа:
   2 × (0,70 × 11) = 15,4
```
Разница 40% в пользу отказа от бафа. **Так считается любой баф на следующий
удар: двухходовка против двухходовки.**
