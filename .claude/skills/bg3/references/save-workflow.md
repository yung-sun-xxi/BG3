# Сейв из Steam Cloud в `current/`

Игрок играет через Boosteroid под своим Steam-аккаунтом, поэтому сейвы лежат в
Steam Cloud и качаются без установки игры. Игры на маке нет.

## Три шага

1. **Найти свежий сейв.** Игрок должен быть залогинен в Steam в браузере
   (встроенный браузер, `mcp__Claude_Browser__*`). Список BG3, appid 1086940:
   `https://store.steampowered.com/account/remotestorageapp/?appid=1086940`.
   Страница отдаёт 50 строк без ссылок на следующие: добирать через
   `&index=50`, `&index=100` (всего файлов около 100, из них ~97 `.lsv`).
   Удобнее одним `fetch` из `javascript_tool` по трём индексам, чем листать.
   Дата в таблице без года, формат «9 сен в 23:47». Брать самый свежий `.lsv`;
   при одинаковой минуте - больший номер. Ссылка «Загрузить» ведёт на
   `https://cdn.steamusercontent.com/filedownload/<id>` и качается `curl -L`
   без куки.
2. **Прочитать.** В каталоге проекта:
   ```
   scripts/update_party.sh <путь>/QuickSave_NNN.lsv
   ```
   Скрипт переносит файл в `.agent/saves/<имя>/` (в гит не попадает),
   распаковывает, читает и кладёт `party.md`, `party.json`, `pool.md` в
   `current/`. Последняя строка вывода - контрольная: число персонажей, надетых
   вещей, снаряжения в пуле, непроверенных, заклинаний, черт, СЛ заклинаний.
3. **Показать разницу.** `git diff current/` против прошлого сейва: уровень,
   класс, черты, слоты, что прибыло в пул. Это и есть отчёт игроку, плюс
   таблица партии из `current/party.md`. Затем закоммитить `current/` и
   `src/gear.csv`, если он вырос.

## Две ловушки

- Два числа в блобе меняются от сейва к сейву: тег записи индекса компонентов
  и флаг строкового литерала. Оба читаются из файла. Если новый сейв падает
  с `KeyError: 'core.v0.EntityId'` или имена партийцев стали «сущность N»,
  а подготовленные заклинания пустые - сначала эти два числа, потом раскладки.
- Характеристики в сейве итоговые, вместе с надетым. Базы нет. Перчатки
  ловкости ставят ЛОВ 18 при базе 8, и по числу этого не видно.

## Что считается снаряжением

Только надеваемое: оружие, броня, аксессуары. Зелья, свитки, еда, квестовые
вещи, лагерная одежда и бельё в пул не попадают. Список «что можно надеть» -
`src/gear.csv`, растёт сам на каждом сейве: надето кем-то в боевом слоте -
`yes`; префикс и последнее слово stat id оба говорят «снаряжение» - `yes`;
только одно из двух - `?`, и такие строки перечислены в конце `pool.md` под
«Не проверено». Игрок проверяет их один раз и ставит `yes` или `no` в
`gear.csv`; проставленное руками читалка не перезаписывает.
